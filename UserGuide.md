# SynAnalyzer User Guide

## Overview
This source code can be considered a semi-automated image analysis pipeline for quantifying the density of paired and
unpaired synaptic markers, their association with tdTomato (tdT) signal, and other properties in a given high-resolution
micrograph of a wholemount preparation of cochlear sensory epithelium. To do this it relies on the user providing a
spreadsheet that contains the xyz coordinates for every region of interest in the micrograph. For the purposes of the
Franco et al manuscript, these spreadsheets are automatically generated by Imaris from synaptic marker surface reconstructions. 
Each surface reconstruction encapsulates the fluorescence signal created by a synaptic marker punctum. Imaris calculates the
center of this reconstruction, its volume, and the mean fluorescence intensity within this surface for each channel in the
micrograph, along with several other features that were not analyzed in the Franco et al manuscript. With this xyz coordinates
and the original micrograph, the code generates a set of arrays that show a maximum projection image of the region of interest
(i.e., centered at the given xyz coordinate), which the user then manually evaluates. Following user scoring, the code
compiles the data from the manual analysis along with the original outputs from Imaris to calculate the values presented in
manuscript. 

To achieve this, the image analysis pipeline is broken down into several steps. First, the spreadsheets generated in Imaris
are converted in Python friendly dataframes so that Pandas can be used to efficiently compute values of interest. In this step,
key image metadata is added to each entry within the dataframe so that a single surface ID can always be traced back to its
original image and to the originating fluorescence channel (i.e., whether the surface reconstruction was generated from the
ribbon or PSD immunolabelling). These dataframes are saved as new CSV files that can be easily read by ImageJ. The second step
in the pipeline is running an ImageJ macro that identifies all available micrographs and CSV files. It then opens an image-CSV
file pair and generates a set of thumbnail maximum projection images at each location in the CSV file. These thumbnails are then
compiled into an array. The macro walks the user through manually scoring each image for its "synaptic" status (i.e., whether or
not the thumbnail shows a paired ribbon and PSD. CSV files generated from PSD fluorescence are also scored for their "terminal" status
(i.e., whether or not the PSD signal overlaps closely with the tdT signal). 

Once all image-CSV file pairs have been analyzed according to the user wishes, two additional Python notebooks are used to 
complete the analysis. In the first, the data from all CSV files is compiled into a master "XYZSummary" dataframe. This single
dataframe has one entry for every single reconstruction analyzed along with all of its relevant metadata such as the originating
image, animal ID, experimental condition/group, etc. Within this same notebook, two new values are calculated for each surface.
An "image maximum normalized tdT intensity" is calculated using the mean tdT intensity within a synaptic PSD, as calculated by
Imaris. The code takes the brightest value in the corresponding image and normalizes the mean tdT intensity of all surfaces to 
this value and saves the information in a new column in the dataframe. Additionally, a "control median normalized volume" is
calculated by finding the median volume for the control group, across all images in that group, and then dividing all volumes
in all images by this value. This new value is also saved as a new column in the dataframe. This Python notebook also summarizes
the data for each image (e.g., PSD-based Paired Synapse Index, tdT+ Synapse Proportion, etc.) and saves this information in 
a new CSV file called "BatchMaster." In the final notebook of the source code, Python code reads in the BatchMaster file and the 
XYZSummary file so that it can generate plots of the underlying data and the user can perform any desired statistical or secondary 
analysis.

## Step 1: Setting up the experiment metadata
SynAnalyzer expects that image and experiment metadata is saved in two different CSV files with specific heading names. These
heading names can be altered within the Python notebooks and ImageJ macro. However, it is easiest to follow the conventions 
originally used here. These are detailed below and can be seen in the demo dataset files:
* SynAnalyzer_BatchName.Metadata.Imaging.csv (note that this is a good sheet to also track all imaging parameters used for easy reference):
  * SampleID
  * Turn (i.e., which cochlear turn was imaged)
  * RegionID (i.e., used in the case when multiple images are acquired from the same cochlear turn)
  * Frequency (i.e., the corresponding tonotopic frequency of the imaged region)
  * HairCellsReconstructed (i.e., the number of hair cells for each synaptic marker puncta were reconstructed in Imaris)
  * ImageName (note that the code expects all image filenames to follow the convention shown in the demo files and below)
    * Image naming convention: SampleID.TwoCharacterTurnID.TwoCharacterRegionID.Zs.NumberOfFluorescentChannelsC.czi


* SynAnalyzer_BatchName.Metadata.Samples.csv (note that this is a good sheet to also track animal information and any other experiment
data associated with the sample):
  * SampleID
  * AnimalID
  * Group
